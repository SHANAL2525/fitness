# Koncepthive Fitness Gym Website

A responsive promotional fitness website created for the **Web Development Internship Evaluation**.

This project was designed and developed for a local fitness brand launching a new gym.  
It showcases the gym’s services, membership plans, trainers, and includes a contact form for user inquiries.
